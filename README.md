# Jakeartspace — Creative Design Studio

A responsive, single-page portfolio website for Jakeartspace, built with HTML and CSS.

## Sections
- Home / studio introduction
- About and design tools
- Selected works (clearly labelled concept studies for now)
- Services: presentation, graphic, and social media design
- Process
- Contact

## Before publishing
1. Replace the temporary contact address `hello@example.com` with the studio's real email.
2. Replace the four concept-study panels with images of actual portfolio projects.
3. Add social profile links if desired.
4. Review the service descriptions and studio introduction.

The current work panels are illustrative HTML/CSS concept studies, not claims of commissioned client projects.

## Enable GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment to finish. The site will be available at the repository's GitHub Pages URL.
